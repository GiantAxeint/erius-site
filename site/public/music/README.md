# site/public/music/

把下载好的歌曲文件放进本目录即可。

## 用法

- 支持的格式：`.mp3`、`.m4a`、`.ogg`、`.wav`、`.aac`、`.flac`
- 文件名（不含后缀）会作为歌名显示在播放器里
- 例如：`Starry Sky.mp3` → 播放器显示「Starry Sky」
- build 时会自动扫描本目录，无需额外配置
- 推荐体积：单首 ≤ 8 MB，目录总大小 ≤ 50 MB（GitHub 仓库单文件 100 MB 限）
